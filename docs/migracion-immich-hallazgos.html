🔍 Query para Extraer Álbumes

Una vez se obtenga acceso a la BD, esta query devuelve todos los álbumes con sus archivos, lista para migrar a Immich:

-- Álbumes + archivos del usuario alonso
SELECT
    a.id         AS album_id,
    a.name       AS album_name,
    a.create_time,
    a.item_count,
    u.id         AS unit_id,
    u.filename,
    u.filesize,
    f.name       AS folder_name,
    -- Reconstruir ruta completa
    '/volume1/homes/alonso/Photos/' || f.name || '/' || u.filename AS full_path
FROM normal_album a
JOIN many_item_has_many_normal_album m ON m.id_normal_album = a.id
JOIN item i ON i.id = m.id_item
JOIN unit u ON u.id_item = i.id
JOIN folder f ON f.id = u.id_folder
WHERE a.id_user = (SELECT id FROM dsm_user WHERE name = 'alonso')
ORDER BY a.name, m.sequence;

🗺️ Plan de Migración Recomendado

Paso 1 — Desbloquear la BD de Synology Photos

Conectarse como root a la NAS y ejecutar:

psql -U SynologyPhotos -d synofoto \
  -c "SELECT a.id, a.name, a.item_count
      FROM normal_album a
      JOIN dsm_user u ON u.id = a.id_user
      WHERE u.name = 'alonso'
      ORDER BY a.name;"

Si falla autenticación peer, editar pg_hba.conf para permitir trust local temporalmente.

Paso 2 — Extraer datos y generar mapeo

Ejecutar la query completa de álbumes → archivos y exportar a CSV/JSON:

psql -U SynologyPhotos -d synofoto -c "\copy (
  SELECT a.name AS album, f.name AS folder, u.filename
  FROM normal_album a
  JOIN many_item_has_many_normal_album m ON m.id_normal_album = a.id
  JOIN item i ON i.id = m.id_item
  JOIN unit u ON u.id_item = i.id
  JOIN folder f ON f.id = u.id_folder
  WHERE a.id_user = (SELECT id FROM dsm_user WHERE name = 'alonso')
  ORDER BY a.name, m.sequence
) TO '/tmp/albums_alonso.csv' CSV HEADER;"

Paso 3 — Migrar a Immich con immich-go

Dos enfoques viables:

  1. External Library: Montar /volume1/homes/alonso/Photos/ en Immich como :ro. Luego usar immich-folder-album-creator para convertir carpetas en álbumes.
  2. Upload con álbumes preservados: Crear un script que lea el CSV de álbumes y llame a immich-go from-folder por cada álbum con --album "Nombre".

Para MobileBackup y PhotoRequest, usar immich-go from-folder --folder-as-album ya que tienen nombres descriptivos.

Paso 4 — Post-migración

  • Ejecutar jobs de Generate Thumbnails y Storage Template Migration en el panel de Admin de Immich
  • Ejecutar Face Detection y Facial Recognition
  • Desplegar immich-folder-album-creator si se necesita sincronización continua de carpetas → álbumes
